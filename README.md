# Classifier Comparison

Учебное сравнение шести моделей классификации: Logistic Regression, KNN, Decision Tree, Random Forest, Gradient Boosting и SVM.

Проект из учебного портфолио Антона Никитина. Исходные наработки сохранены; подготовка документации и публикации выполнена с помощью ИИ.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook ml.ipynb
```

## Состав и ограничения

Для запуска положите исходные `train.csv` и `test.csv` рядом с ноутбуком. Данные и прежние выводы ячеек исключены. Ноутбук показывает подготовку признаков, обучение и сравнение по accuracy; значения метрик требуют повторного запуска.

В репозиторий включён исходный код. Локальные пароли, окружения, базы, журналы и частные наборы данных исключены. Результаты и метрики не заявляются без воспроизводимой проверки.
